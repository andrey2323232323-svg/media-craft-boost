# Источники изображений

Восемь скриншотов предоставлены заказчиком. Оригиналы сохранены в public/images; кадрирование выполнено при отображении через SVG viewBox и clipPath. Интерфейс управления сообществами не показывается.

Логотипы:
- ТМК — знак с предоставленного скриншота ЧТПЗ/ТМК.
- Росатом — https://logo-teka.com/en/rosatom/ (русская версия SVG).
- Синара — https://www.sinara-group.com/press-center/ (официальный пресс-кит).
- Strogoorganic — https://strogoorganic.ru/ (logo-01.png).
- Россия 24 — https://commons.wikimedia.org/wiki/File:Rossiya-24_Logo.svg (автор: Россия 24; PD-textlogo).

Для кейса «Есть решение» предоставлены только примеры материалов: показатели эффективности и внешняя ссылка не добавлялись. Данные остальных кейсов сохранены из исходного сайта; цифры в предоставленных скриншотах могут относиться к другому периоду.

Логотипы hero: ТМК — https://freebiesupply.com/logos/tmk-logo/ (SVG); Росреестр — https://glavgeocom.ru/images/clients/approved-20261020/rosreestr.webp (оригинальный знак, монохромное отображение через CSS). Остальные — существующие файлы из раздела клиентов.
